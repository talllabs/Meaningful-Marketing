HAC website style guide

One simple guide for every staff member who updates the website. These colors, fonts and blocks are built into the editor, so every page looks like HAC. In the real project, we would build this from HAC's existing brand standards.

Colors

Concept colors inspired by rural America: navy, wheat and field green. Every text color passes WCAG 2.2 AA contrast (4.5:1 or higher). The numbers below are the real contrast ratios.

Navy#1F4E79Links, buttons, headings · 8.7:1 on white ✓
Deep Navy#12304DHeadings, footer · 13.5:1 on white ✓
Wheat#E3B04BMain action buttons, with dark text · 8.2:1 ✓
Field Green#8DB48EDecoration only. Never use for text (2.3:1 ✗)
Ink#18212FBody text · 16.2:1 on white ✓
Slate#4A5568Secondary text · 7.5:1 on white ✓

Font

Atkinson Hyperlegible. It was made by the Braille Institute to be easier to read for people with low vision. Letters that look alike, like I, l and 1, are easy to tell apart.

Il1 O0 rn m

Body text is 18px or larger. Lines are kept short and easy to follow.

Buttons

Three styles only. Every button is at least 48px tall, so it is easy to tap.

How we write

The editor checks these rules as staff type.

Write for every audience

Lead with a plain summary. Save the technical detail for further down the page.

Every report gets a web page

A summary, key findings and an accessible PDF, so people can find it in search.

Spell out short forms

Write "U.S. Department of Agriculture (USDA)" the first time.

Describe every chart

Each chart gets a short text summary and a data table.

Make links say where they go

"Read the full report," not "click here."

Tag everything

Type, topic and year on every resource, so the library filters work.
